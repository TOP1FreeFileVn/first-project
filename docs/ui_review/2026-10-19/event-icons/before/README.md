# Trước lượt sửa icon cửa hàng và sự kiện

Giữ lại ảnh có sẵn trước lượt sửa này, không chụp lại từ code đang thay đổi:

- `lobby_720x1280.png`, `lobby_360x640.png`: từ `nav-icons/battle_*`, render native ở từng kích thước.
- `shop_720x1280.png`: từ `screens/02_shop.png`.
- `events_720x1280.png`: từ `screens/09_events.png`.

Shop và popup sự kiện chưa có ảnh trước ở 360×640; không dùng bản resize làm ảnh native.

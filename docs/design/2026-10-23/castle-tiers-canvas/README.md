# Castle tiers — canvas pilot (2026-10-23)

Brief
- Visual thesis: the same cat's cardboard-box castle grows up as the player upgrades it,
  from a taped shipping box to a painted cat palace. Every tier keeps the approved
  silhouette (tall centre keep with cat ears, two shorter side towers, cat-head gate).
- Defining contour: the keep's cat ears + crenellated top; side towers stay lower.
- Materials: cardboard tan `#d9a86a` / shade `#c48f52`, tape `#e8cf98`, ink `#583f21`,
  teal flag `#6aa9a8`; later tiers add paint red `#d8645a`, cream `#f2e3c4`, gold `#e9b949`.
- Lobby view, front-facing flat 2D like `reference.png` (the approved castle-crop.png).

Tiers (2 castle levels each)
1. Hộp carton — current look.
2. Thùng gia cố — tape crosses, patches, extra fish flag.
3. Tháp đôi — side towers taller with paper cone roofs, lit paw windows.
4. Lâu đài sơn — painted roofs and banners, curtain gate, fish bell.
5. Cung điện mèo — gold-trimmed ears, big banner, lanterns, guard cat silhouettes.

# Background music

Cozy acoustic style (kalimba / marimba / soft bass), E major, to match the
wooden gear sounds in `game/audio/gear`. `MusicLib` (autoload) plays it.

| Track | Where | Notes |
|---|---|---|
| `lobby` | Home and its pages | 84 BPM |
| `battle` | Battle, shop break | 96 BPM, calm layer |
| `battle_drive` | Battle, while a wave fights | Same length as `battle`; bass + soft drums faded in on top |

The `.wav` files are placeholders generated by `python tools/audio/make_music.py`
(original synthesis, no third-party audio). Their import settings loop them.

## Replacing a track with a downloaded one

1. Pick a cozy loop from a free library: Pixabay Music (free, no credit needed),
   OpenGameArt (only CC0 tracks), or incompetech (CC BY: credit the author).
   Search words: cozy, lofi acoustic, kalimba, cafe, cute game loop.
2. Save it here as `lobby.ogg` or `battle.ogg`. An `.ogg` wins over the `.wav`.
3. In Godot, select the file, open the Import dock, tick **Loop**, then **Reimport**.
4. A downloaded `battle.ogg` plays alone: the generated drive layer is skipped
   because it would not match another song's key and tempo.

Keep the license / source of each downloaded track in this file.
